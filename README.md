# learning from nature

An autumn beech wood seen from the ground, painted in Three.js. As soon as the page loads, the camera flies straight up through the canopy into the sky, where it says hello fall. Scroll down and the words shrink away; scroll back up and they grow from half size into view.

Live at https://mudranagda.github.io/learning-from-nature/, served by GitHub Pages from the `main` branch. The page is `index.html`.

To run it locally, serve the folder:

```bash
python3 -m http.server 4420
```

then visit http://localhost:4420.
